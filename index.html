Лабораторная работа №1 — Цветовые модели

RGB ↔ LAB ↔ CMYK. Все преобразования реализованы вручную без библиотек конвертации.

100%

Расчёт

Для RGB ↔ LAB используется промежуточная модель XYZ. Матрица RGB → XYZ рассчитывается по выбранному стандарту освещения, а обратная матрица получается обратным вычислением.

Автоматические микро-тесты

Проверяются RGB → LAB, RGB → CMYK, обратимость преобразований и пересчёт матриц. Подробный ход выполнения тестов выводится в консоль браузера (F12).

Архитектура: Model (чистая математика) → View (DOM) → Controller (синхронизация).
