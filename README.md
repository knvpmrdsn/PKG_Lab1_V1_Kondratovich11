# Лабораторная работа №1 — Цветовые модели

Вариант 1

## Возможности

- Поддерживаются D65, D50 и E.
- CMYK поддерживает GCR и UCR, плюс регулируемую силу замены серой составляющей на K.
- Для обратного XYZ/LAB→RGB доступны Clipping и Scaling.
- Каждый слайдер имеет динамический градиент, вычисленный из текущих значений остальных компонент.
- Есть числовой ввод, палитра и слайдеры.
- Все модели автоматически синхронизируются.
- Есть ненавязчивое предупреждение о выходе за gamut.
- Архитектура разделена на Model / View / Controller.
- Микро-тесты запускаются автоматически и повторно по кнопке.

## Структура

- `js/model/color-math.js` — математика.
- `js/view/app-view.js` — построение и обновление интерфейса.
- `js/controller/app-controller.js` — обработка действий пользователя и связь View - Model.
- `tests/tests.js` — тесты.
- `css/styles.css` — оформление.
